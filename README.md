# Open Finance Space

## Überblick

Open Finance Space ist ein Projekt zur Entwicklung einer modernen, sicheren und erweiterbaren Finanzsoftware-Plattform.

Das Repository enthält Konzepte, Architekturentscheidungen, Dokumentationen und zukünftig den Quellcode des Projekts.

## Zielsetzung

Das Projekt verfolgt das Ziel, eine transparente und wartbare Grundlage für moderne Finanzanwendungen zu schaffen.

Dabei stehen folgende Aspekte im Mittelpunkt:

- Sicherheit
- Erweiterbarkeit
- klare Architektur
- nachvollziehbare Entscheidungen
- moderne Softwareentwicklung
