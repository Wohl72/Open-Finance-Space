# ADR-0001: Projektgrundlage Open Finance Space

## Status

Akzeptiert

## Kontext

Open Finance Space wird als Plattform für Finanzsoftware entwickelt.
Ziel ist eine nachvollziehbare, sichere und erweiterbare Architektur.

## Entscheidung

Das Projekt verwendet Architecture Decision Records (ADR), um wichtige technische Entscheidungen nachvollziehbar zu dokumentieren.

Die Dokumentation wird versioniert im Repository verwaltet.

## Konsequenzen

- Architekturentscheidungen bleiben nachvollziehbar.
- Änderungen können später begründet werden.
- Neue Entwickler erhalten einen besseren Einstieg.

## Alternativen

Keine zentrale Architektur-Dokumentation zu führen wurde verworfen.
