# Architecture Decision Records (ADR)

Dieses Verzeichnis dokumentiert wichtige Architekturentscheidungen des Projekts.

## Zweck

Architecture Decision Records (ADRs) halten technische Entscheidungen, deren Kontext und Konsequenzen nachvollziehbar fest.

## Format

Jede ADR sollte folgende Struktur verwenden:

1. Titel
2. Status
3. Kontext
4. Entscheidung
5. Konsequenzen
6. Alternativen

## Nummerierung

ADRs werden fortlaufend nummeriert:

- ADR-0001-Beschreibung.md
- ADR-0002-Beschreibung.md
